# Ex.No.4 – EXPERIMENT 4
# Prompt Generation & Evaluation Using Different Prompt Types


## REGISTER NUMBER: 212223090023

## Aim:

To generate prompts for five different prompt types and evaluate them using an evaluation method (Rubric).
The prompts are based on the given Industry 4.0 automation use case using IoT & embedded systems.

## Scenario:

The manufacturing industry requires automation to reduce manual monitoring and increase production efficiency. Using IoT devices and embedded controllers, the system will automate equipment, monitor performance, and offer predictive maintenance.

### Target Audience

Manufacturing companies in sectors such as:

- Automotive

- Electronics

- Food processing

### Main Objectives

- Improve production efficiency by 30%

- Reduce machinery downtime using predictive maintenance

- Enable real-time monitoring and remote control

- Reduce energy consumption with optimized processes

## Prompt Types (From Unit 2 Applied to Unit 5 Use Case)

Below are the five prompts designed based on the use case.

### 1. Comparative Analysis Prompt

**Definition**

A prompt that compares two systems, methods, technologies, or models to highlight similarities, differences, and performance gaps.

**Generated Prompt**

Compare traditional manual machine monitoring with IoT-enabled real-time monitoring in manufacturing. Discuss accuracy, response time, cost, downtime reduction, workforce needs, and decision-making improvements.

**Why This Prompt Is Useful**

Helps decision-makers choose between legacy systems vs. modern IoT

Useful for cost-benefit analysis

Encourages deeper AI reasoning


### 2. Experiential Perspective Prompt

**Definition**

A prompt written from the viewpoint of a specific stakeholder, enhancing personalization and context.

**Generated Prompt**

As a production manager in an automotive manufacturing unit, describe how IoT-based predictive maintenance affects your daily workflow, machine uptime, reporting process, and shift planning.

**Why This Prompt Is Useful**

Gives AI role-based context

Produces realistic responses

Helps understand user experience and needs


### 3. Everyday Functioning Prompt

**Definition**

Prompts that relate technical concepts to everyday experiences, making them easy to understand for non-technical readers.

**Generated Prompt**

Explain how IoT-powered machines in a factory function similarly to everyday smart devices like smart fans, smart lights, or smart thermostats. Highlight automation, sensing, and remote control.

**Why This Prompt Is Useful**

Simplifies learning

Great for beginners and presentations

Connects complex systems to familiar examples



### 4. Universal Prompt Structure

**Definition**

A general-purpose prompt format like "Explain", "Describe", "List", or "Step-by-step".

**Generated Prompt**

Explain step-by-step how to implement an IoT-based predictive maintenance system, starting from sensor installation to cloud analytics and notification alerts. Include components, communication protocols, and real-world examples.

**Why This Prompt Is Useful**

Very clear

Produces structured, instructional output

Useful for documentation and training


### 5. Prompt Size Limitation Prompt

**Definition**

Prompts that handle large tasks by breaking them into manageable segments.

**Generated Prompt**

List 40 benefits of IoT in manufacturing. Provide the first 10 benefits now, then continue in sets of 10 upon request.

**Why This Prompt Is Useful**

Prevents overwhelming AI output

Helps organize large lists

Ideal for long research tasks


### Evaluation Method – Rubric (Used to Evaluate All Prompts)

A simple 5-criteria rubric is used to evaluate prompt quality.



| Criteria          | Score Range | Description                                       |
| ----------------- | ----------- | ------------------------------------------------- |
| **Clarity**       | 1–5         | Is the prompt clear and easy to understand?       |
| **Relevance**     | 1–5         | Is it relevant to the IoT manufacturing use case? |
| **Completeness**  | 1–5         | Does it provide necessary context?                |
| **Specificity**   | 1–5         | Does it specify scope & expectations?             |
| **Actionability** | 1–5         | Can an AI tool respond effectively?               |
